# FORME — учебный интернет-магазин одежды

Курсовой проект: каталог, поиск и фильтрация, корзина, оформление учебного заказа, управление товарами, три отчёта и два графика. Реальных платежей и доставки нет.

**Технологии:** React/Vite, C++17, модуль Apache HTTP Server, SQLite. API и фронтенд работают через один Apache. Модуль загружается директивой `LoadModule`, получает HTTP-запросы через `SetHandler` и обращается к SQLite через C API. Данные заказов и складских остатков хранятся на сервере.

## Быстрый запуск на Linux / Windows

Установите Docker с поддержкой Linux-контейнеров, затем в папке проекта:

```sh
docker build -t forme .
docker run --rm -p 8080:80 -v forme-data:/var/lib/forme forme
```

Откройте http://localhost:8080. При первом запросе появятся демонстрационные товары. Данные хранятся в томе Docker `forme-data`, поэтому сохранятся после остановки контейнера. Доступен учебный режим без авторизации: не публикуйте его в интернет как настоящий магазин.

## Проверка

При запущенном приложении выполните `python tests/smoke.py`. Проверка создаёт тестовые заказы и товар. Для чистой базы используйте отдельный временный том.

## Как устроен проект

- `frontend/src` — интерфейс React.
- `backend/mod_store.cpp` — C++ модуль Apache: чтение каталога, изменение товаров, запись заказов и выдача данных отчётов.
- `docker-apache.conf` — настройка `SetHandler` и пути к базе.
- `Dockerfile` — сборка интерфейса и модуля Linux, запуск Apache.
- `.github/workflows/check.yml` — сборка контейнера и проверка API в GitHub Actions.

Заказ записывается одной транзакцией. Сервер берёт цену из базы, проверяет остаток и уменьшает его; если товар закончился, весь заказ отменяется. Отчёты и графики формируются из сохранённых заказов.

## Сборка на Linux без Docker

Для Debian/Ubuntu установите Apache, `apache2-dev`, `g++`, `libsqlite3-dev`, `nlohmann-json3-dev`, Node.js и npm. В `frontend` выполните `npm install` и `npm run build`; разместите содержимое `frontend/dist` в DocumentRoot. Модуль можно собрать командой:

```sh
apxs -c -S CC=g++ -Wc,-std=c++17 backend/mod_store.cpp -lsqlite3
```

Полученный `.so` подключают к совместимой сборке Apache через `LoadModule store_module /путь/к/mod_store.so`. Пример настройки обработчика и переменной пути к БД приведён в `docker-apache.conf`. Каталог базы должен быть доступен на запись пользователю Apache.

## Windows

Вариант Docker выше запускает **Linux-версию** в контейнере на Windows; это не нативная Windows-сборка. Для нативной сборки предусмотрен `backend/CMakeLists.txt`: потребуется совместимый с установленным Apache компилятор MSVC, библиотеки и заголовки Apache/APR, SQLite и nlohmann/json. Укажите путь к Apache параметром `-DAPACHE_ROOT=...`, а пути к зависимостям — через `CMAKE_PREFIX_PATH`. Apache на Windows часто использует расширение `.so` для модулей, хотя это DLL. Эта нативная сборка пока **не проверена** и может потребовать настройки под конкретную сборку Apache.

## Ограничения

Приложение предназначено для учебной локальной демонстрации: авторизации и защиты административных функций нет. Время заказов хранится в UTC. Для показа и защиты стоит заранее создать несколько заказов, чтобы отчёты и графики были заполнены.
